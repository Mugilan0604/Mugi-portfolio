Real-World Bug Report Structure

Example of detailed, actionable defect documentation provided to engineering teams

BUG-204 Severity: High Priority: P1
Status: Verified & Closed

Checkout submit button remains disabled when entering valid 10-digit postal code with trailing space

Environment: Chrome 124 / Windows 11 / Staging v2.4
Module: Billing & Payment Gateway
Discovered During: Boundary Value Regression Run
Steps to Reproduce:
  1. Log into the application and add any product to the shopping cart.
  2. Proceed to checkout and fill all mandatory address fields.
  3. In the "Postal Code" input field, type "600001 " (valid code followed by a single space).
  4. Observe the "Proceed to Payment" submit button state.
Expected Result:

Input field trims whitespace automatically; validation succeeds and button enables.

Actual Result:

Regex rejects trailing space; button remains disabled with no descriptive error message.
